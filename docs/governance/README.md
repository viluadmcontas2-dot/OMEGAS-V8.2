# Governança ativa

A governança ativa do OMEGAS é repo-first e está limitada a:

1. `AGENTS.md`;
2. `PROJECT.md`;
3. `STATUS.md`;
4. WorkUnit ativa em `docs/workunits/`;
5. manifesto de evidências em `docs/evidence/`;
6. Issue/branch/PR ligados à WorkUnit.

Planos, incidentes e contratos antigos permanecem como histórico técnico. Quando conflitarem com os arquivos acima, não controlam o estado atual. Notion e Linear são referências opcionais de estratégia/histórico e não bloqueiam boot, execução ou fechamento técnico.

Decisões arquiteturais novas entram em `docs/adr/`. Evidência só é válida quando identifica o SHA exato, o comando/gate e o limite do que foi provado.
